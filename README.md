# 🚚 Mark-3 Mini-TMS (RAUM Logix)

**Mark-3 Mini-TMS** — це інтерактивна та візуально преміальна система управління транспортом (Transportation Management System), створена для демонстрації сучасних підходів у логістиці, автоматизації тендерів та моніторингу рейсів у реальному часі.

Цей проект розроблено як інноваційне доповнення до професійного резюме в сфері логістики та управління ланцюгами постачання.

---

## 🌟 Ключові можливості (Features)

### 1. 🗺️ Жива GPS-Карта (Leaflet.js)
* Інтерактивне відстеження вантажівок на карті Європи.
* Диференціація типів кузовів: рефрижератори підсвічуються **неоновим бірюзовим сяйвом**, звичайні тенти — **синім**.
* Автоматичне фокусування та прокладання оптимального маршруту для новозатверджених рейсів із спливаючими вікнами інформації.

### 2. 📡 Моніторинг IoT-Телеметрії
* Динамічний графік температури вантажу в реальному часі для рефрижераторів (підтримання діапазону від **+2°C до +5°C**).
* Зчитування швидкості та статусу з віртуальних GPS-трекерів.
* Миттєві сповіщення про відхилення показників.

### 3. ⚡ Автоматизований Радар-Тендер (Simulated Bidding)
* Симуляція масового тендеру серед перевізників (*EuroTrans UA, Lviv Express, Dnipro Trucking, InterCargo Poland*).
* Живий радар торгів та автоматичний вибір переможця за критерієм **максимальної маржинальності** для компанії.

### 4. 🧠 R.A.U.M. Copilot AI (Асистент Логіста)
* Інтегрований розумний чат-бот для швидких дій:
  * **Оптимізація ставок** — автоматичний пошук вигідніших рішень та розрахунок маржі.
  * **Інструкції водію** — генерація детальних інструкцій для водіїв (адреси, температурний режим, CMR) у буфер обміну.
  * **Черги на кордонах** — швидкий моніторинг часу очікування на КПП з Польщею (Ягодин, Краківець, Рава-Руська).

### 5. 📟 Cyberpunk Лог-Термінал
* Жива стрічка логів, що імітує підключення до державних баз митниці та GPS-трекерів вантажівок.

## 🛠️ Технологічний стек

* **Frontend:** Чистий HTML5 та CSS3 (змінні, Glassmorphic дизайн, анімації).
* **Скрипти:** Vanilla JavaScript (модульна структура, симуляція потоку даних).
* **Картографія:** [Leaflet.js](https://leafletjs.com/) + OpenStreetMap.
* **Графіки:** [Chart.js](https://www.chartjs.org/) для плавної телеметрії.
* **Хостинг/Деплой:** Готові конфігураційні файли для миттєвого розгортання на [Vercel](https://vercel.com).

## 🚀 Як запустити локально

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Raum369/Mark-3-Mini-TMS.git
   ```
2. Перейдіть у папку з проектом:
   ```bash
   cd Mark-3-Mini-TMS
   ```
3. Відкрийте файл `index.html` у будь-якому браузері (або запустіть локальний сервер, наприклад, через Live Server у VS Code).

## 📈 Бізнес-цінність проекту
Система демонструє розуміння концепцій **Control Tower (вежі управління)**, автоматизації торгів (bidding), моніторингу холодового ланцюга (cold chain monitoring) та застосування штучного інтелекту для оптимізації щоденної роботи логіста-диспетчера.
